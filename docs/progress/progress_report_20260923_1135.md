## 🎯 작업 목적

16개로 늘어난 메뉴 탭으로 인해 상단 네비게이션이 복잡해지는 문제를 해결하기 위해,
**맨 위의 로고를 메뉴 줄로 내리고, 로고를 포함하여 메뉴 전체를 깔끔한 2줄(Row 1, Row 2) 구조로 재배치**함.

1. **`Header.jsx` 레이아웃 2줄 분할 개편**
   - **Row 1**: [🥕 당근 PCB 메이커스 로고] + [설계/제작 8개 탭: 홈, 작업실, 설계 계산기, 거버 뷰어, 회로 스케치, BOM 관리, 발주 트래커, 나눔 & 공구] + [우측: 프로필 위젯, 온도 필, 계정 전환, 알림 벨, 다크 모드 토글]
   - **Row 2**: [커뮤니티/활동 8개 탭: 공유 장비, 일정 & 밋업, 커뮤니티, 실시간 채팅, 챌린지, 지식 위키, 멘토링, 활동 통계] + [우측: + 작업 등록, 관리자 화면 ADMIN]
