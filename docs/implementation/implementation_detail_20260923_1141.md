## 🏛️ 최적화된 헤더 2줄 레이아웃 구조

사용자 피드백을 반영하여, **좌측 로고가 2개 행 전체에 걸쳐 당당하고 안정적인 공간**을 차지하고,
**"당근 PCB" 브랜드 타이틀과 "메이커스" 배지를 명확히 분리**하였습니다.  
또한 계정 정보, 계정 전환, 작업 등록, 관리자 화면 등 모든 사용자 액션을 **아래 라인(Row 2) 우측**으로 모아 배치하고, 1번째 줄(Row 1)에는 10개의 핵심 도구 및 장터 메뉴를 넓고 시원하게 배치하였습니다.

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ ┌─ 좌측 로고 (2줄 걸침) ─┐  [홈] [작업실] [설계 계산기] [거버 뷰어] [회로 스케치] [BOM 관리] [발주 트래커] [나눔 & 공구] [공유 장비] [일정 & 밋업] │
│ │ 🥕 [PCB] 당근 PCB    │                                                                                                  │
│ │   [메이커스]          │  [커뮤니티] [실시간 채팅] [챌린지] [지식 위키] [멘토링] [활동 통계]   [+작업등록] [프로필/온도] [계정전환] [🔔][🌙] [ADMIN] │
│ └──────────────────────┘                                                                                                  │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 📋 세부 구성 내역

### 1. 좌측 로고 영역 (`logo-container`)
- **2줄 전체 높이 점유**: 상하 2개 줄의 네비게이션 높이에 맞춰 48x48px 엠블럼과 텍스트가 좌측에 안정적으로 배치
- **타이포그래피 분리**:
  - `당근 PCB`: 1.25rem 두꺼운 메인 볼드 타이포 (`logo-brand-main`)
  - `메이커스`: 오렌지색 포인트 테두리와 배경을 가진 독립 뱃지 태그 (`logo-brand-badge`)로 시각적 분리 완료
- **구분선**: 우측 2줄 네비게이션 컬럼과의 경계에 섬세한 버티컬 디바이더 라인 적용

### 2. 첫 번째 줄 (Row 1 — 설계·제작·장터 라인 10개 탭)
1. `홈` (`Home`)
2. `작업실` (`Layers`)
3. `설계 계산기` (`Calculator`)
4. `거버 뷰어` (`Eye`)
5. `회로 스케치` (`PenTool`)
6. `BOM 관리` (`FileSpreadsheet`)
7. `발주 트래커` (`Truck`)
8. `나눔 & 공구` (`Package`)
9. `공유 장비` (`Wrench`)
10. `일정 & 밋업` (`Calendar`)

### 3. 두 번째 줄 (Row 2 — 커뮤니티 라인 6개 탭 + 통합 액션 바)
- **좌측 커뮤니티 탭 (6개)**:
  1. `커뮤니티` (`MessageSquare`)
  2. `실시간 채팅` (`MessagesSquare`)
  3. `챌린지` (`Trophy`)
  4. `지식 위키` (`BookOpen`)
  5. `멘토링` (`GraduationCap`)
  6. `활동 통계` (`TrendingUp`)
- **우측 통합 액션 바**:
  - `+ 작업 등록` (새 PCB 프로젝트 등록)
  - `프로필 위젯` (아바타, 닉네임, 등급/온도 Pill 버튼)
  - `계정 전환` (데모 계정 간편 전환 / 회원가입)
  - `알림 벨` (실시간 알림 드롭다운)
  - `다크 모드 토글` (Sun/Moon 테마 전환)
  - `관리자 화면 ADMIN` (운영진 대시보드 바로가기)
