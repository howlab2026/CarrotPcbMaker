## 🏛️ 상단 헤더 개편 상세

사용자 요청에 따라 메뉴의 중복성을 줄이고 로고의 완성도를 높였습니다:

1. **'홈' 메뉴 탭 제거 & 로고 홈 기능 통합**
   - 상단 1번째 줄 네비게이션에서 별도의 `'홈'` 탭을 제거하였습니다.
   - 좌측의 2줄 엠블럼 로고(`logo-container`)를 클릭하면 언제든지 즉시 홈 대시보드(`dashboard`)로 이동하도록 인터랙션을 강화하였습니다.
   - 호버 시 로고 박스 미세 확대(scale 1.05) 및 오렌지색 섀도우, 타이틀 툴팁("당근 PCB 메이커스 홈으로 이동")을 적용하여 클릭 가능한 링크임을 직관적으로 인지할 수 있도록 하였습니다.

2. **'메이커스' 폰트 크기 확대 및 스타일 최적화**
   - `'당근 PCB'` 메인 타이틀(1.25rem 볼드) 아래에 위치한 `'메이커스'` 태그 폰트 크기를 기존 `0.72rem`에서 `0.88rem`으로 확대하였습니다.
   - 패딩(`2px 8px`), 라운딩(`6px`), 오렌지 테두리 및 배경 틴트를 적용하여 시각적 존재감과 안정적인 밸런스를 확보하였습니다.

## 📋 헤더 네비게이션 최종 구성 (총 15개 메뉴)

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ ┌─ 좌측 로고 (클릭 시 홈 이동) ─┐  [작업실] [설계 계산기] [거버 뷰어] [회로 스케치] [BOM 관리] [발주 트래커] [나눔 & 공구] [공유 장비] [일정 & 밋업] │
│ │ 🥕 [PCB] 당근 PCB            │                                                                                                  │
│ │   [메이커스 (확대)]           │  [커뮤니티] [실시간 채팅] [챌린지] [지식 위키] [멘토링] [활동 통계]   [+작업등록] [프로필/온도] [계정전환] [🔔][🌙] [ADMIN] │
│ └──────────────────────────────┘                                                                                                  │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

- **Row 1 (9개 탭)**: `작업실`, `설계 계산기`, `거버 뷰어`, `회로 스케치`, `BOM 관리`, `발주 트래커`, `나눔 & 공구`, `공유 장비`, `일정 & 밋업`
- **Row 2 (6개 탭 + 액션 6개)**:
  - 탭: `커뮤니티`, `실시간 채팅`, `챌린지`, `지식 위키`, `멘토링`, `활동 통계`
  - 액션: `+ 작업 등록`, `사용자 정보/온도`, `계정 전환`, `알림 벨`, `다크 모드`, `관리자 화면 ADMIN`
