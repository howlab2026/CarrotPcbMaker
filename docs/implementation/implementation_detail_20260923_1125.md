## 📋 컴포넌트별 구현 현황 (총 16개 핵심 뷰)

### 1. `Header.jsx` — 네비게이션 & 헤더 액션
- **네비게이션 탭**: 홈, 작업실, 설계 계산기, 거버 뷰어, 회로 스케치, BOM 관리, 발주 트래커, 나눔 & 공구, 공유 장비, 일정 & 밋업, 커뮤니티, 실시간 채팅, 챌린지, 지식 위키, 멘토링, 활동 통계
- **알림 센터 연동**: 종 모양 아이콘 + 읽지 않은 알림 배지 + 드롭다운 알림 목록
- **다크 모드 토글**: Sun/Moon 아이콘을 통한 라이트/다크 테마 즉시 전환 (localStorage 연동)
- **납땜 온도 & 레벨 위젯**: 불꽃 아이콘 + 6단계 레벨 이모지 + 온도 실시간 표시
- **우측 액션**: 새 작업 등록, 유저 프로필 모달, 간편 계정 전환, 관리자 화면(ADMIN)

### 2. `SchematicNotepad.jsx` — 회로 스케치 메모장 (신규 ✨)
- **HTML5 Canvas 엔진**: 고해상도 회로도 및 핀맵 브라우저 직접 스케치
- **도구 팔레트**: 펜, 지우개, 직선/와이어, 사각형/IC, 원형/패드
- **12종 회로 기호 스탬프**: 저항(R), 커패시터(C), 인덕터(L), 다이오드(D), LED, GND, VCC, NPN 트랜지스터, IC 칩, 스위치, 배터리, 크리스탈
- **선 굵기 & 8종 색상 팔레트**: 기판 블랙, 당근 오렌지, PCB 에메랄드, 블루, 레드 등
- **모눈 그리드 토글 & Undo/Redo & PNG 이미지 저장**

### 3. `OrderTracker.jsx` — 기판 발주 트래커 (신규 ✨)
- **5단계 칸반 파이프라인**: 주문 접수 📝 → 기판 제작중 🏭 → SMT 부품실장 🤖 → 국제 배송중 ✈️ → 수령 완료 ✅
- **종합 요약 지표**: 진행중인 발주, 수령 완료 건수, 총 발주 비용 (USD 및 KRW 환산)
- **카드 인터랙션**: D-Day 카운트다운, 제조사 태그(JLCPCB, PCBWay 등), 송장 번호, 사양(층수, 수량, SMT 포함 여부), 단계 전진/후퇴
- **새 발주 등록 모달**: 주문번호, 층수, 수량, 비용, 도착 예정일, 메모 입력

### 4. `WikiView.jsx` — 메이커 지식 위키 (신규 ✨)
- **카테고리 분류**: 전체, 설계 기초, 소자 선택, 발주 가이드, 납땜 팁, 트러블슈팅
- **실시간 통합 검색**: 제목, 마크다운 본문, 태그(#KiCad, #DRC 등) 검색
- **상세 뷰어**: 구조화된 마크다운 렌더링, 조회수 카운트, 도움돼요(좋아요) 토글
- **새 지식 문서 작성 모달**: 카테고리 지정, 태그 입력, 본문 마크다운 에디터

### 5. `MentoringView.jsx` — 메이커 멘토링 매칭 (신규 ✨)
- **1:1 멘토-멘티 매칭 시스템**: 전문 분야별 멘토링 프로그램 탐색 및 신청
- **멘토 자격 검증**: 당근 납땜 온도 50℃ 이상 보유자만 멘토 프로그램 개설 가능
- **실시간 매칭 & 채팅 연결**: 멘티 신청 즉시 매칭 완료 및 1:1 대화방(DM) 다이렉트 이동
- **새 멘토 개설 모달**: 주제, 전문 분야 태그, 지도 방식 안내

### 6. `StatsView.jsx` — 활동 히트맵 & 통계 분석 (신규 ✨)
- **GitHub 스타일 26주(6개월) 잔디 히트맵**: 날짜별 활동량에 따른 5단계 잔디 색상 시각화
- **4대 핵심 요약 카드**: 총 활동 횟수, 납땜 온도 상승치, 최장 활동 스트릭, 보유 뱃지 수
- **활동 유형별 분포 바 차트**: 회로 설계(38%), 커뮤니티/SOS(32%), 공구/발주(18%), 밋업(12%)
- **명예의 전당 (Leaderboard)**: 상위 랭킹 5인 메이커 순위, 레벨, 납땜 온도 표시

### 7. `ChallengeView.jsx` — 주간 챌린지 & 콘테스트 (신규 ✨)
- **챌린지 라이프사이클**: 진행중인 챌린지, 예정된 챌린지, 종료된 챌린지 탭
- **출품작 갤러리**: 메이커들의 기판 사진, 스펙, 설계 설명
- **투표 시스템**: 추천/투표 토글 및 실시간 득표수 집계
- **작품 제출 모달**: 프로젝트명, 설명, 기판 렌더 이미지 제출

### 8. `BomManager.jsx` — BOM 관리 & 원가 계산기 (신규 ✨)
- **BOM 목록 및 실시간 편집**: 부품명, 파트넘버, 수량, 단가, 유통사(LCSC, DigiKey, Mouser), 패키지
- **원가 자동 합산**: 총 부품 원가($ USD) 및 실시간 환율 적용 원화(KRW) 변환
- **부품 DB 검색**: Mock 유통사별 가격 비교 및 원클릭 BOM 추가
- **CSV 내보내기/가져오기 기능**

### 9. `NotificationCenter.jsx` — 실시간 알림 센터 (신규 ✨)
- **헤더 알림 벨 드롭다운**: 미확인 알림 뱃지 표시
- **알림 유형**: 댓글 알림, 좋아요 알림, 공구 참여 알림, 밋업 D-Day 알림, SOS 답변 채택 알림
- **읽음 처리 & 해당 뷰 바로가기 연동**

### 10. `ProfileModal.jsx` — 프로필 & 6단계 등급 체계 (업그레이드 ✨)
- **6단계 메이커 등급 체계 카드 추가**:
  - Lv.1 🌱 새싹 메이커 (36.5 ~ 39.9℃)
  - Lv.2 🔥 납땜 견습생 (40.0 ~ 49.9℃)
  - Lv.3 ⚡ 회로 장인 (50.0 ~ 64.9℃)
  - Lv.4 💎 아트웍 대가 (65.0 ~ 79.9℃)
  - Lv.5 👑 PCB 마스터 (80.0 ~ 94.9℃)
  - Lv.6 🏆 전설의 납땜러 (95.0 ~ 99.9℃)
- **온도 게이지 & 업적 뱃지 7종 도감 완비**

## 🗄️ 백엔드 및 클라이언트 저장소 (Mock API) 확장

| 엔드포인트 | 메서드 | 설명 |
| :--- | :---: | :--- |
| `/api/orders` | GET / POST | 기판 발주 목록 조회 / 새 발주 등록 |
| `/api/orders/:id` | PUT / DELETE | 발주 상태 단계 이동 / 발주 삭제 |
| `/api/wiki` | GET / POST | 지식 위키 목록·검색 / 새 문서 발행 |
| `/api/wiki/:id` | PUT | 위키 조회수 증가 및 좋아요 토글 |
| `/api/mentoring` | GET / POST | 멘토링 프로그램 목록 / 새 멘토 프로그램 등록 |
| `/api/mentoring/:id` | PUT | 멘티 매칭 및 세션 횟수 업데이트 |
| `/api/challenges` | GET / POST | 주간 챌린지 목록 조회 / 새 챌린지 개설 |
| `/api/challenges/:id/vote` | POST | 챌린지 출품작 투표 토글 |
| `/api/bom` | GET / POST | BOM 목록 조회 / 새 BOM 저장 |
| `/api/bom/:id` | PUT / DELETE | BOM 수정 / 삭제 |
| `/api/parts/search` | GET | 부품 파트넘버 검색 및 유통사별 가격 비교 |
| `/api/notifications` | GET / PUT | 유저 알림 목록 / 읽음 일괄 처리 |
