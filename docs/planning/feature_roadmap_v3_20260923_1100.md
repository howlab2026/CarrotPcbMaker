## 🎯 기획 방향

현재 v2.0까지 구현된 **13개 핵심 기능**을 기반으로, 아래 세 가지 방향으로 확장합니다:

1. **🔧 설계 도구 고도화** — 실질적인 PCB 설계 지원 도구
2. **🤝 커뮤니티 깊이 확장** — 더 풍부한 사용자 간 상호작용
3. **📊 운영·분석 강화** — 관리자 및 플랫폼 인텔리전스

## 📋 Phase 4 — 설계 도구 고도화

### 4-1. 🔌 BOM 관리 & 부품 가격 비교 도구 ⭐ HIGH PRIORITY

**목적**: 프로젝트에 등록한 BOM(Bill of Materials)을 기반으로 주요 부품 유통사별 가격을 한눈에 비교

| 항목 | 내용 |
| :--- | :--- |
| **기능** | BOM CSV/Excel 업로드, 부품 검색, 가격 비교 표, 총 원가 계산 |
| **컴포넌트** | `BomManager.jsx` (신규) |
| **데이터** | `bomItems` 배열 (파트넘버, 수량, 단가, 유통사) |
| **연동** | 기존 `Workspace` 프로젝트의 BOM 필드와 연결 |
| **참조 유통사 (Mock)** | 디지키, 마우저, LCSC, 엘레파츠 |

**MVP 기능**:
- 부품 번호 입력 → Mock 가격 데이터 표시
- BOM 리스트 편집 (추가/삭제/수량 변경)
- 총 원가 자동 합산 + 환율 적용 (USD→KRW)
- 프로젝트 연결: 작업실의 프로젝트에 BOM 매핑

---

### 4-2. 📐 회로 스케치 메모장 (Schematic Notepad)

**목적**: 간단한 회로 스케치를 브라우저에서 직접 그려서 게시판/채팅에 공유

| 항목 | 내용 |
| :--- | :--- |
| **기능** | Canvas 기반 자유 그리기, 기본 소자 스탬프 (저항, 커패시터, IC 등), PNG 내보내기 |
| **컴포넌트** | `SchematicNotepad.jsx` (신규) |
| **활용** | 게시판 글 작성/채팅 메시지에 회로 스케치 첨부 |
| **라이브러리** | 없음 (순수 Canvas API) |

**MVP 기능**:
- 펜 도구 (색상, 굵기 선택)
- 지우개, 되돌리기/다시하기 (Undo/Redo)
- 기본 소자 스탬프 12종 (저항, 커패시터, 인덕터, 다이오드, LED, 트랜지스터, IC, GND, VCC, 와이어, 스위치, 커넥터)
- PNG/SVG 내보내기

---

### 4-3. 📦 발주 트래커 (Order Tracker)

**목적**: JLCPCB, PCBWay 등 해외 기판 발주 상태를 개인 대시보드에서 추적

| 항목 | 내용 |
| :--- | :--- |
| **기능** | 발주 정보 수동 등록 (주문번호, 업체, 수량, 예상도착일), 상태 업데이트, 히스토리 |
| **컴포넌트** | `OrderTracker.jsx` (신규) |
| **데이터** | `orders` 배열 (유저별, 상태: 주문완료→제작중→배송중→도착) |
| **연동** | 작업실 프로젝트와 연결 가능 |

**MVP 기능**:
- 발주 정보 등록 폼 (업체, 수량, 층수, 마감일)
- 파이프라인 뷰 (칸반 스타일 상태 보드)
- 도착 예상 D-Day 카운트다운

## 📋 Phase 5 — 커뮤니티 깊이 확장

### 5-1. 🏆 주간 챌린지 & 콘테스트 ⭐ HIGH PRIORITY

**목적**: 매주 주제별 PCB 설계 챌린지를 개최하여 참여와 경쟁 유도

| 항목 | 내용 |
| :--- | :--- |
| **기능** | 챌린지 개설 (운영진), 작품 제출, 투표, 결과 발표, 명예의 전당 |
| **컴포넌트** | `ChallengeView.jsx` (신규) |
| **데이터** | `challenges` 배열 (주제, 기간, 제출 작품, 투표) |
| **보상** | 납땜 온도 +3℃, 특별 뱃지 (🏆 챌린지 우승자) |

**예시 챌린지 주제**:
- "가장 작은 면적의 ESP32 보드"
- "아트웍이 가장 아름다운 기판"
- "가장 창의적인 LED 매트릭스 회로"

---

### 5-2. 📚 지식 위키 (Knowledge Base)

**목적**: 반복되는 PCB 설계 팁, FAQ, 소자 선택 가이드 등을 위키 형태로 축적

| 항목 | 내용 |
| :--- | :--- |
| **기능** | 카테고리별 문서 작성/편집, 태그 검색, 인기 문서 랭킹 |
| **컴포넌트** | `WikiView.jsx` (신규) |
| **데이터** | `wikiArticles` 배열 (제목, 내용, 태그, 수정이력) |
| **카테고리 (초기)** | 설계 기초, 소자 선택, 발주 가이드, 납땜 팁, 장비 리뷰, 트러블슈팅 |

---

### 5-3. 💬 멘토링 매칭 시스템

**목적**: 초보 메이커와 경험자를 1:1 멘토-멘티로 매칭

| 항목 | 내용 |
| :--- | :--- |
| **기능** | 멘토 등록 (전문 분야, 가용 시간), 멘티 신청, 매칭 알림, 세션 기록 |
| **컴포넌트** | `MentoringView.jsx` (신규) |
| **조건** | 납땜 온도 50℃ 이상만 멘토 등록 가능 |
| **보상** | 멘토링 완료 시 양측 온도 +2℃, 뱃지 (🎓 멘토 마스터 / 🌱 성장 멘티) |

---

### 5-4. 🔔 알림 센터 (Notification Center)

**목적**: 댓글, 좋아요, 공구 모집 마감, 밋업 D-Day 등 주요 이벤트 알림

| 항목 | 내용 |
| :--- | :--- |
| **기능** | 헤더 벨 아이콘 + 드롭다운, 읽음/안읽음 상태, 카테고리 필터 |
| **컴포넌트** | `NotificationCenter.jsx` (신규) |
| **데이터** | `notifications` 배열 (유저별, 타입, 대상 ID, 읽음 여부) |
| **트리거** | 댓글, 좋아요, 공구 참여, 밋업 D-1, SOS 채택 |
