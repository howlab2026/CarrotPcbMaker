## 📋 컴포넌트별 구현 상세

### 1. `Header.jsx` — 상단 네비게이션

- **상단 행**: 로고 + 9개 메뉴 탭 (홈, 작업실, 설계 계산기, 거버 뷰어, 나눔&공구, 공유 장비, 일정&밋업, 커뮤니티, 실시간 채팅)
- **하단 행**: 작업 등록 버튼, 유저 프로필 위젯 (아바타+이름+역할+온도), 계정 전환, 관리자 버튼
- **납땜 온도 위젯**: `Flame` 아이콘 + 실시간 온도 표시 (클릭 시 프로필 모달)

### 2. `Dashboard.jsx` — 홈 대시보드

- 환영 메시지 + 당근 대시보드 통계 카드 4종 (회원, 프로젝트, 밋업, 게시글)
- D-Day 임박 밋업 배너
- 최신 공개 PCB 작업물 피드 (갤러리 카드)
- CTA 버튼 → 작업실, 커뮤니티 등 바로가기

### 3. `Workspace.jsx` — 작업실 & 갤러리

- **탭 구분**: 내 작업물 / 공유 갤러리
- **카드 UI**: 썸네일 + 스펙 (층수, MCU, BOM) + 공개/비공개 토글
- **상세 모달**: 회로도·기판 이미지, 좋아요, 댓글 스레드
- **CRUD**: 작업물 생성/수정/삭제/공개전환

### 4. `CalendarView.jsx` — 일정 & 밋업

- **월간 캘린더 뷰**: 날짜별 이벤트 표시
- **이벤트 카드**: 날짜, 시간, 장소, 참석 인원 / 최대 인원
- **RSVP**: 참석 신청/취소 토글
- **이벤트 등록**: 운영진 전용 새 이벤트 생성 폼

### 5. `BoardView.jsx` — 5종 테마 게시판 + SOS

- **5개 게시판 탭**: 공지사항, 정보게시판, 일반게시판, 비밀게시판, 건의사항
- **6번째 특수 게시판**: 🆘 SOS 클리닉
  - PCB 사진 위에 핀포인트 마킹 (클릭 좌표 기반)
  - 댓글 채택 → 해결 완료 처리 + 도우미 온도 +1.5℃
- **건의사항**: 처리 상태 배지 (접수 → 검토중 → 반영완료)
- **비밀게시판**: 자동 익명 닉네임 부여

### 6. `ChatView.jsx` — 실시간 채팅

- **4개 멀티 채널**: 자유수다방, 회로&아트웍 Q&A, 부품 공구 나눔, 오프라인 번개
- **1:1 DM**: 상대방 아바타 + 이름 표시, 실시간 전송
- **메시지 UI**: 말풍선 스타일, 타임스탬프, 이모지 반응

### 7. `PcbCalculator.jsx` — 설계 계산기

- **다중 계산기 탭**: 임피던스, 전류 용량, 비아 열저항, 열 해석, RC 필터 등
- **실시간 계산**: 입력값 변경 시 즉시 결과 반영
- **시각적 다이어그램**: 단면도 및 파라미터 설명

### 8. `GerberViewer.jsx` — 거버 뷰어

- **파일 파싱**: Gerber RS-274X, Excellon 드릴 포맷 지원
- **레이어 뷰**: 개별 레이어 on/off 토글
- **캔버스 렌더링**: 줌, 패닝, 좌표 표시

### 9. `MarketView.jsx` — 나눔 & 공구 장터

- **탭**: 전체 / 부품 나눔 / 해외 공구
- **필터**: 카테고리, 상태, 검색
- **카드 UI**: 진행률 바, 참여 인원, D-Day
- **참여**: 공구 참여/취소 토글

### 10. `EquipmentView.jsx` — 동네 공유 장비

- **카테고리 필터**: 납땜, 측정, 제작, 공구
- **카드 UI**: 장비 사진, 스펙, 위치, 상태 (이용가능/대여중)
- **연락하기**: DM 채팅으로 바로 연결

### 11. `ProfileModal.jsx` — 메이커 프로필 & 뱃지 도감

- **온도계 시각화**: 36.5℃~99.9℃ 그래디언트 바
- **뱃지 도감**: 획득한/미획득 뱃지 리스트 (이모지 + 설명)
- **활동 통계**: 작업물 수, 게시글 수, 참여 공구 수 등

### 12. `AdminPanel.jsx` — 운영진 관리자 화면

- **회원 관리**: 역할 변경 (정회원 ↔ 운영진 ↔ 활동정지)
- **건의사항 관리**: 처리 상태 일괄 업데이트
- **활동 통계**: 전체 지표 대시보드

## 🗄️ API 엔드포인트 목록

| Method | Endpoint | 설명 |
| :---: | :--- | :--- |
| POST | `/api/upload` | 파일 업로드 (DataURL 변환) |
| GET | `/api/users` | 전체 유저 목록 |
| POST | `/api/auth/login` | 로그인 |
| POST | `/api/auth/register` | 회원가입 |
| PUT | `/api/users/:id` | 유저 정보 수정 |
| GET | `/api/stats` | 전체 통계 |
| GET/POST | `/api/projects` | 프로젝트 목록/생성 |
| GET/PUT/DELETE | `/api/projects/:id` | 프로젝트 상세/수정/삭제 |
| POST | `/api/projects/:id/like` | 좋아요 토글 |
| POST | `/api/projects/:id/comments` | 댓글 작성 |
| GET/POST | `/api/posts` | 게시글 목록/생성 |
| GET/PUT/DELETE | `/api/posts/:id` | 게시글 상세/수정/삭제 |
| POST | `/api/posts/:id/like` | 좋아요 토글 |
| POST | `/api/posts/:id/comments` | 댓글 작성 |
| POST | `/api/posts/:id/accept-solution` | SOS 해결책 채택 |
| GET/POST | `/api/events` | 이벤트 목록/생성 |
| POST | `/api/events/:id/rsvp` | RSVP 참석 토글 |
| GET | `/api/channels` | 채팅 채널 목록 |
| GET | `/api/dm/:u1/:u2` | DM 스레드 조회/생성 |
| GET/POST | `/api/market` | 마켓 목록/등록 |
| POST | `/api/market/:id/join` | 공구 참여/취소 |
| GET/POST | `/api/equipment` | 장비 목록/등록 |
