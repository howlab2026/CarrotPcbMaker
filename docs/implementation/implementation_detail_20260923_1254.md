## 🖥️ 상단 헤더 2줄 네비게이션 & 로고 구조

```
┌────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ ┌─ 좌측 로고 (클릭 시 홈 이동) ─┐  [작업실] [설계 계산기] [거버 뷰어] [회로 스케치] [BOM 관리] [발주 트래커] [나눔 & 공구] [공유 장비] [일정 & 밋업] │
│ │ 🥕 [PCB] 당근 PCB            │                                                                                                  │
│ │   [메이커스] (0.88rem 배지)   │  [커뮤니티] [실시간 채팅] [챌린지] [지식 위키] [멘토링] [활동 통계]   [+작업등록] [프로필/온도] [계정전환] [🔔][🌙] [ADMIN] │
│ └──────────────────────────────┘                                                                                                  │
└────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

- **좌측 로고 (`logo-container`)**: 2개 행 전체 높이를 안정적으로 점유. 클릭 시 홈(`dashboard`)으로 즉시 이동. 마우스 호버 시 미세 확대(`scale 1.05`) 및 오렌지 섀도우 연출.
- **브랜드 타이포 분리**:
  - `당근 PCB`: 1.25rem 볼드 메인 브랜드 타이포 (`logo-brand-main`)
  - `메이커스`: 0.88rem 오렌지 포인트 틴트 뱃지 태그 (`logo-brand-badge`)
- **Row 1 (상단 줄, 9개 탭)**: `작업실`, `설계 계산기`, `거버 뷰어`, `회로 스케치`, `BOM 관리`, `발주 트래커`, `나눔 & 공구`, `공유 장비`, `일정 & 밋업`
- **Row 2 (하단 줄, 6개 탭 + 6개 액션)**:
  - 네비게이션 탭: `커뮤니티`, `실시간 채팅`, `챌린지`, `지식 위키`, `멘토링`, `활동 통계`
  - 우측 액션 바: `+ 작업 등록`, `사용자 정보/온도 (프로필 모달 연결)`, `계정 전환`, `알림 벨`, `다크 모드 토글`, `관리자 화면 ADMIN`

## 🌡️ 당근 납땜 온도 & 6단계 등급 체계

| 등급 | 칭호 | 온도 범위 | 아이콘 | 주요 혜택 및 자격 |
| :---: | :--- | :---: | :---: | :--- |
| **Lv.1** | **새싹 메이커** | 36.5 ~ 39.9℃ | 🌱 | 신규 가입 기본 등급, 게시판 및 작업실 이용 |
| **Lv.2** | **납땜 견습생** | 40.0 ~ 49.9℃ | 🔥 | 공구/나눔 참여 및 챌린지 출품 |
| **Lv.3** | **회로 장인** | 50.0 ~ 64.9℃ | ⚡ | **1:1 멘토 프로그램 개설 자격 획득** |
| **Lv.4** | **아트웍 대가** | 65.0 ~ 79.9℃ | 💎 | 챌린지 심사위원 추천 자격 |
| **Lv.5** | **PCB 마스터** | 80.0 ~ 94.9℃ | 👑 | 오프라인 정기 밋업 호스트 자격 |
| **Lv.6** | **전설의 납땜러** | 95.0 ~ 99.9℃ | 🏆 | 명예의 전당 영구 헌액 |

## 🗄️ 백엔드 및 Mock API 엔드포인트 목록

| 엔드포인트 | 메서드 | 처리 내용 |
| :--- | :---: | :--- |
| `/api/users` | GET / PUT | 전체 유저 목록 / 유저 정보(역할, 온도, 뱃지) 수정 |
| `/api/auth/login` | POST | 간편 로그인 및 계정 전환 |
| `/api/auth/register` | POST | 신규 회원가입 |
| `/api/stats` | GET | 플랫폼 전체 통계 지표 집계 |
| `/api/projects` | GET / POST | PCB 프로젝트 목록 / 새 작업물 등록 |
| `/api/projects/:id` | GET / PUT / DELETE | 프로젝트 상세 / 수정 / 삭제 |
| `/api/posts` | GET / POST | 게시글 목록 / 새 글 작성 |
| `/api/posts/:id/accept-solution` | POST | SOS 답변 채택 및 도우미 온도 +1.5℃ 지급 |
| `/api/orders` | GET / POST | 기판 발주 목록 / 새 발주 등록 |
| `/api/orders/:id` | PUT / DELETE | 발주 5단계 상태 변경 / 발주 내역 삭제 |
| `/api/wiki` | GET / POST | 지식 위키 목록·검색 / 새 지식 문서 발행 |
| `/api/wiki/:id` | PUT | 위키 조회수 증가 및 좋아요 토글 |
| `/api/mentoring` | GET / POST | 멘토링 목록 / 새 멘토 프로그램 등록 |
| `/api/mentoring/:id` | PUT | 멘티 매칭 및 세션 횟수 업데이트 |
| `/api/challenges` | GET / POST | 챌린지 목록 / 출품작 등록 |
| `/api/challenges/:id/vote` | POST | 챌린지 출품작 투표/추천 |
| `/api/bom` | GET / POST | BOM 목록 / 새 BOM 생성 |
| `/api/bom/:id` | PUT / DELETE | BOM 수정 / 삭제 |
| `/api/parts/search` | GET | 파트넘버 검색 및 유통사별 가격 비교 |
| `/api/notifications` | GET / PUT | 알림 목록 / 읽음 일괄 처리 |
